# 分摊

一个面向 Excel 费用分摊的工作台：每个批次重新上传余额表，按费用信息分组、精确计算、补充开票信息并生成可核对的结果文件。

- [`site/`](site/)：网站源代码及运行、测试说明。
- [`skill/invoice-cost-allocation/`](skill/invoice-cost-allocation/)：用于 Codex 工作流的费用分摊 Skill。

网站提供自己的账号登录，采用 Node.js、SQLite 和本地对象存储。导入数据、生成文件和批次记录留在部署环境中；本仓库不包含实际业务表格、数据库或运行密钥。

网站支持配置 DeepSeek，提供辅助录入和批次解释；调用相关功能时，必要数据会发送至 DeepSeek。每个新批次都必须重新上传余额表，网站不维护共享余额，也不会自动沿用上一批余额。DeepSeek 识别、精确试算、开票模板上传和文件生成都在网站内完成，最终由使用者核对并确认本批完成。

Skill 是独立的 Codex 指令与脚本，仓库中的文件不会自动安装或连接网站。网站和 Skill 均描述部门空值兼容规则；Skill 中旧版单来源规划和核验脚本不支持该规则，不能将其输出当作新规则核验。

当前网站不提供共享余额或跨批次余额同步。每一批都是一个独立任务：上传本批余额表，生成结果，人工确认完成；下一批再上传上一批的剩余表。旧版共享账簿入口已从网站界面移除，历史数据只留在数据库审计中，不再参与新批次计算。
